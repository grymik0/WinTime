## Что такое WinTime?

WinTime тихо работает в системном трее Windows, отслеживая активность активного окна, аптайм процессов, вкладки браузеров и рабочие проекты без нагрузки на систему и процессор.

Никакой облачной синхронизации, телеметрии или создания аккаунтов — **100% ваших данных хранятся исключительно в локальной базе данных SQLite на вашем компьютере**.

## Технологический стек

- **Платформа**: WPF (.NET 10, C# 13)
- **Интерфейс**: Собственные стили Fluent Design, бесшовное окно `WindowChrome`, динамические словари ресурсов
- **Графики**: [LiveChartsCore](https://livecharts.dev/) 2.0.5 (SkiaSharp)
- **База данных**: SQLite через [Microsoft.Data.Sqlite](https://learn.microsoft.com/en-us/dotnet/standard/data/sqlite/) 10.0 + [Dapper](https://github.com/DapperLib/Dapper) ORM
- **Иконка в трее**: [Hardcodet.NotifyIcon.Wpf](https://github.com/hardcodet/wpf-notifyicon) 1.1
- **Экспорт**: [CsvHelper](https://joshclose.github.io/CsvHelper/) 33
- **Архитектура**: Паттерн MVVM (лёгкие реактивные свойства, модульный реестр сервисов)

## Установка и запуск

### Запуск из исходного кода

```bash
git clone https://github.com/your-username/WinTime.git
cd WinTime
dotnet run -p:Platform=x64
```

### Сборка через Visual Studio

1. Откройте файл `WinTime.sln` в **Visual Studio 2022** (v17.10+) или JetBrains Rider.
2. Выберите конфигурацию **Release | x64** (или **Debug | x64**).
3. Назначьте `WinTime` запускаемым проектом (Startup Project).
4. Нажмите **F5** для запуска.

### Сборка автономного исполняемого файла (Self-Contained)

Чтобы получить единый `.exe` файл, которому не требуется предварительно установленный .NET:

```bash
dotnet publish WinTime.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

### Первый запуск

При первом запуске WinTime откроется окно быстрой настройки, где можно выбрать язык интерфейса (Русский или English) и папку для хранения файла базы данных `.db` (по умолчанию: `%LOCALAPPDATA%\WinTime`). Сразу после выбора приложение автоматически начнёт учёт времени и свернётся в системный трей.

## Политика конфиденциальности

Приватность — ключевой принцип создания WinTime:
- **Никакой телеметрии** и аналитики использования.
- **Никаких дампов падений**, отправляемых на внешние сервера.
- **Ни единого сетевого запроса**: приложение физически не обращается к интернету.
- Все заголовки окон, временные метки и журналы работы хранятся исключительно на вашем диске.
